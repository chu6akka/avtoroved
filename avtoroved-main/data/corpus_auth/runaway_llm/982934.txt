В прессе и X вирусится история Яаны Доган, Principal Engineer в Google, которая рассказала, как якобы Claude Code за час решил задачу, над которой целая команда трудилась примерно год. После вопросов и критики со стороны коллег, Яана написала ряд уточнений — и история стала даже более интересной. Давайте разбираться! Что произошло? Доган отвечает за Gemini API в Google. На выходных она решила протестировать Claude Code на задаче, которая не дает покоя ее команде с прошлого года: distributed agent orchestrators — системы, которые координируют работу нескольких ИИ-агентов. Далее Яана описала проблему Claude Code и он за час создал то, "на что команда потратила целый год". Что же именно создал Claude Code? После волны репостов Доган уточнила детали: Команда Google не сидела сложа руки весь год. Они построили несколько версий системы, но каждая имела свои компромиссы. Консенсуса не было. Claude Code получил на вход не сырую задачу, а дистиллят — лучшие идеи, которые выжили за год исследований. Результат Claude Code — не готовый к продакшену продукт, а "toy version", то есть прототип. Но Доган признается: она удивлена качеством, так как не давала подробных указаний по архитектуре, а Claude Code сам предложил толковые решения. "Строить уже не сложно" Дальше Доган пишет, возможно, самое важное в данной истории. Она разделяет два процесса. Первый — годы, чтобы понять предметную область, обкатать идеи в реальных продуктах, выработать паттерны, которые не развалятся со временем. Это нельзя ускорить, только прожить. Второй — сама реализация. И вот тут с приходом ИИ все изменилось: когда понимание есть, построить решение с нуля стало тривиальной задачей. Доган добавляет важный нюанс про корпоративный контекст: в большой компании инфраструктура должна работать для десятков команд и сценариев. Отсюда год дискуссий — не потому что команда медленная, а потому что решение должно подходить всем. А ИИ позволяет эксперту за час собрать чистый прототип, свободный от этих компромиссов и legacy-багажа. «Час вместо года» — полуправда. Claude Code не заменил год работы команды. Он взял концентрат из года исследований и превратил его в рабочую отправную точку. Но, может, это и есть главный сдвиг: годы опыта начинают конвертироваться в часы кода. Если знаешь, что строить.
