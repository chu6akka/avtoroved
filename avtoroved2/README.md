# aved — автороведческая идентификация «от методики»

Инструмент судебно-автороведческой **идентификационной** экспертизы, реализующий процесс из
методики **Рубцова И.И., Ермолова Е.И. и др. «Комплексная методика производства
судебно-автороведческих экспертиз»** (ЭКЦ МВД России, 2007).

Программа — **помощник эксперта**: она воспроизводит методический каркас (4 стадии, признаки
по уровням НН/НС/НСВ, правило вывода), но решение принимает эксперт.

## Каркас идентификации (методика, с. 80–86)

1. **Оценка пригодности** объектов (спорный текст и образцы).
2. **Раздельное исследование** — модель речемыслительного навыка на каждый текст.
3. **Сравнительное исследование** — по трём уровням индивидуализации навыка.
4. **Оценка совокупности признаков и вывод** — по правилу методики.

## Уровни индивидуализации навыка (с. 11)

- **НН** — набор норм (какими стилями/типом мышления/уровнем языка владеет автор).
- **НС** — набор свойств норм.
- **НСВ** — набор средств выражения свойств. Значимость растёт НН < НС < НСВ.

## Стек

Полностью оффлайн. NLP: **razdel** (сегментация) + **Natasha** (морфология и синтаксис
зависимостей) + **pymorphy3** (детальная морфология). Качественные признаки — **локальная LLM**
через Ollama (опц. Claude API онлайн). Интерфейс — PyQt6. Отчёт — DOCX (python-docx).

## Установка (Windows, Python 3.11+)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[gui,dev]"
```

NLP-модели Natasha поставляются вместе с пакетами и не требуют доступа в сеть.
