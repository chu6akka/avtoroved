# Архив: подсказка модели по кандидатам LanguageTool

Код в этой папке **не подключён к программе** и не поддерживается. Он
сохранён как основание методического вывода: подход был построен, измерен на
эталонном наборе и отвергнут.

## Что это было

Локальная модель предлагала эксперту одну из восьми классификаций
LanguageTool для нераспознанной словоформы. Постановка была намеренно
обратной той, что провалилась у теневых признаков: координаты давал
LanguageTool, ответ был ограничен закрытым списком, модель получала окно
вокруг слова, а не документ. Каждой метке были даны пример и близкий промах.

## Как измеряли

Эталон: `authoroved_core/tests/fixtures/unknown_word_gold.json`, 145
различных словоформ корпуса Pilot 01 с экспертной меткой. В замер вошли 136
(девять относятся к графике, которую восемь лексических классификаций не
покрывают).

Модель `Qwen3-8B-Q5_K_M.gguf`, SHA-256 `068bae16…`, llama.cpp build 10955,
temperature 0, seed 20260914. Результат прогона — `hint_accuracy.json`.

## Результат

| стратегия | точность |
|---|---|
| случайный выбор из восьми меток | 12,5 % |
| **всегда отвечать «имя», не глядя на слово** | **27,2 %** (37 из 136) |
| **модель** | **26,5 %** (36 из 136) |

Модель уступает вырожденной стратегии, которая всегда называет самую частую
метку и текста вообще не читает.

Отклонений валидатора — 0 из 136, воздержаний — 4. То есть контракт
соблюдался, отказала именно классификация.

## Где именно отказала

- **Авторские образования: 0 из 33.** Эту метку модель за весь прогон
  назвала дважды и оба раза ошиблась. `говнодол`, `френдесса`,
  `проэсэмэсила`, `Мапа` отнесены к именам собственным и пробелам словаря.
  Окказионализм — наиболее индивидуализирующий признак письма, то есть отказ
  пришёлся ровно на то, ради чего подход строился.
- **Профессиональная лексика: 0 из 4. Диалектная: 0 из 0 верных при семи
  ответах.**
- Распределение ответов смещено: «имя» модель отвечает в 43 % случаев при
  доле имён в наборе 27 %. Это поведение частотного угадывания, а не разбора.
- Лучшая метка по точности — «разговорная форма», 47,6 %, то есть примерно
  подбрасывание монеты.

Спасаемого подмножества нет: ни одна метка не даёт точности, при которой
подсказку имело бы смысл показывать.

## Почему функция вырезана, а не отключена флагом

Подсказка ошибалась бы в 73 % случаев. Неверная подсказка не нейтральна: она
якорит эксперта, склоняя согласиться с предложенным. Детерминированная
справка этим свойством не обладает, подсказка обладает. Инструмент, который
чаще сбивает, чем направляет, из рабочего контура убран.
